# agent — 1단계: CLI 대화 루프 (단기 기억)

Gemini API를 호출하는 최소 CLI 에이전트. 아직 도구 호출은 없고, 프로세스가 살아있는 동안
대화 이력을 기억하는 것(단기 기억)만 구현되어 있다.

## 준비

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 Gemini API 키를 발급받는다.
2. `.env` 파일을 만든다.

   ```bash


   cp .env.example .env


   ```

3. `.env`의 `GEMINI_API_KEY` 값을 발급받은 키로 채운다.

## 실행

```bash
mvn compile exec:java
```

`나>` 프롬프트에 메시지를 입력하면 답변이 오고, 이어서 다시 물어보면 이전 대화 내용을
기억한 채로 답한다. `exit` 또는 `quit`으로 종료한다.

## 수동 테스트 절차 (1단계 목표 확인용)

1. `mvn compile exec:java` 실행
2. "내 이름은 규림이야" 입력 → 아무 답이나 옴
3. "내 이름이 뭐라고 했지?" 입력 → "규림"이라고 정확히 답하면 단기 기억이 동작하는 것
4. `GEMINI_API_KEY`를 잠깐 지워보고 실행 → 죽지 않고 안내 메시지가 뜨는지 확인
5. `exit` 입력 → 정상 종료되는지 확인
